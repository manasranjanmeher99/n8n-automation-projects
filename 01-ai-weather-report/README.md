# 🌦️ AI Weather Report Automation

## Features

- Scheduled every morning
- Fetches live weather
- Generates AI summary
- Sends Gmail automatically

## Workflow

Schedule
    ↓
Weather API
    ↓
GPT-4.1 Mini
    ↓
Gmail
